## 三、验证方法说明

- PNG / PDF 的「尺寸正确」不是看 UI 显示，而是解析下载文件本身：PNG 读 IHDR 宽高，PDF 用正则提取 `/MediaBox` 换算毫米；
- 「文字重排而非放大预览」由实现保证：导出时把画布世界坐标缩放至目标 dpi 后由 Konva 重新排版绘制全部矢量与文字，源码见 `render/renderer.ts → exportCanvas`；
- 图片丢失检查：导出对话框内置 preflight（越界 / 缺资源 / 缺字体三类），导入 JSON 时缺失资源的图片元素会被丢弃并告警。
